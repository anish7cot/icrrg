# Task 06 — Demo Script & Rehearsal

**Owner:** Team Lead · **Est:** 1 hr

## Before You Start

- [ ] All features work (E2E testing passed — Task 05)
- [ ] Demo data is seeded

## Steps

- [ ] Write a 5-minute demo script with these beats:
  1. **Problem** (30s): "Developers accidentally commit secrets and PHI..."
  2. **Dashboard** (30s): Show metrics, trend charts, populated data
  3. **Live scan** (1 min): Paste diff with secret → show detection
  4. **Code review** (1 min): Show LLM-powered findings with remediation
  5. **Money shot** (1 min): Live git commit blocked by pre-commit hook
  6. **Reports** (30s): Generate leadership report vs developer report
  7. **Close** (30s): "Shift-left security, before code enters history"
- [ ] Assign who presents each section
- [ ] Rehearse twice with timer
- [ ] Write backup plan: "If OpenAI is down, we show cached results from seeded data"

## Challenges

- **Demo gods are cruel.** Always have a pre-recorded video as fallback. Record one successful run.
- **Time management.** 5 minutes goes fast. Cut the talk, show the product.
